Xavrx CFW SD-card layout preview

This archive creates the Xavrx-owned folder structure only.
It is NOT a bootable CFW installer and does not contain boot.firm,
boot.3dsx, ARM9/ARM11 payloads, or a replacement for Luma3DS.

How to use this preview:
1. Extract the archive to the root of the SD card.
2. It creates /xavrx and its data folders.
3. Keep your existing Luma3DS boot.firm and boot.firm settings untouched.

START + POWER is a planned boot-mode shortcut. It is not implemented yet.
Do not use this package to replace boot files or write to NAND.
